Interpretation

No device from the original one-pass connected-state ARP list was reliably absent in the offline state. The connected snapshot was too shallow for a definitive negative comparison: several ordinary LAN devices responded only in the later, stronger sweep. The next discriminating test is a positive one: power the Pi back on, run the same five-retry sweep, and identify the new IPv4/MAC and IPv6 neighbor that is absent from this robust offline baseline.
